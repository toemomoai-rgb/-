# 永慶駕訓班｜自排汽車駕照場考模擬器

以駕駛座視野練習低速前進、倒車、轉向及後照鏡判斷的桌面網頁原型。

**目前是 Milestone 1，使用示意教練車與直線＋90° 彎道測試場。不是永慶駕訓班實際考場重建，也不是正式場考評分系統。**

## 執行

需要 Node.js 22.12+（本環境使用 24.19.0）、npm，以及支援 WebGL 2 的桌面瀏覽器。

```sh
cd /workspace/-
npm ci --cache /workspace/.npm
npm run dev
```

一般本機開發時，將第一行改為自己的專案目錄，再依 Vite 的終端輸出開啟瀏覽器。所有執行時內容皆由專案提供，不依賴外部字型、圖片或 API，不需要帳號或金鑰。

```sh
npm test          # 15 項物理／邊界／校正測試
npm run build    # TypeScript 檢查與正式建置
npm run preview  # 檢查正式建置
npm run test:browser
```

瀏覽器測試優先使用 `/usr/bin/chromium`；其他位置可設定 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`。沒有系統 Chromium 時，先執行 `npx playwright install chromium`。測試使用軟體 WebGL，在沒有 GPU 的環境也能檢查三維視圖。測試自動啟動 Vite；若 5173 已有此專案的伺服器，會重用它。

## 第一次操作

1. 預設是 P 檔、煞車保持開啟、方向盤自動回正關閉。
2. 點選 D 前進或 R 倒車。
3. 點「解除煞車保持」。即使不踩油門也會低速蠕行。
4. 按住 A／D 調整方向盤，放開後角度保持。按住 C 逐漸回正。
5. 隨時按住 S 或空白鍵煞車；完全煞停並持續踩煞車後才能換檔。
6. 方向盤、油門也有按住操作的畫面按鈕；使用滑鼠時可以先開啟「煞車保持」再點選檔位。

| 按鍵 | 功能 |
| --- | --- |
| W | 按住輕踩油門 |
| S／Space | 按住煞車 |
| A／D | 按住向左／右轉方向盤 |
| C | 按住逐漸回正 |
| R／F | 排入 R／D，需要先煞停並保持煞車 |
| Q／E | 切換左／右方向燈 |
| 1 | 駕駛座 |
| 按住 2／3 | 暫時放大左／右後照鏡，放開回到先前視角 |
| 4 | 俯視教學 |

點鏡面下方按鈕或上方視角頁籤可固定放大鏡面。「看左／右側車窗」按鈕需按住，可轉頭觀察。離開視窗時自動暫停並開啟煞車保持；回來後手動繼續。

## 已實作

- 一台示意自排車、P／R／N／D、蠕行、輕油門、煞車、方向燈。
- 低速後軸 bicycle model，前進最高 12 km/h、倒車最高 7 km/h；沒有離合器或競速物理。
- 方向盤連續操作、可見中央標記、角度／圈數、前輪轉向與輪胎滾動動畫。
- 預設駕駛座攝影機、左右觀察方向、教學用俯視攝影機。
- 兩個獨立的即時後視攝影機，以 render target 渲染並水平鏡像，非靜態圖片；同時看到車側與場地白線。
- 0.25×、0.5×、1× 練習速度，暫停分析；俯視顯示固定目前轉角與檔位的四輪預測軌跡。
- 俯視四輪行經軌跡、可選半透明車身。
- 道路邊界檢測：分別檢查四輪與車身周緣；接觸按「一次連續事件」計次。只提供提示，不建立不可穿越的牆。
- 校正面板：眼睛高度、座椅前後／左右、FOV、鏡面角度與視野、車寬／長／軸距、轉向角／比例與方向盤速度。套用會安全重置位置，設定保存在 localStorage。
- 除錯模式：後軸座標、車身角度、方向盤／前輪角度、有向車速、駕駛鏡頭座標，以及俯視車身框、四輪位置、鏡頭視錐。
- 教學提示與自由練習介面。自由練習隱藏操作答案；本階段不保存完成度或正式分數。

## 車輛座標與物理

世界單位為公尺，車輛座標原點在後軸中心。`+x` 向右、`+y` 向上、`-z` 向前。車身角度 0 時朝向世界 `-z`。方向盤與前輪角度為正代表右轉；速度為正代表前進。

```text
前輪轉角 δ = 方向盤角度 / 轉向比
轉彎半徑 R = 軸距 / tan(δ)
車身角變化 Δψ = 有向行程 / 軸距 × tan(δ)
Δx = sin(ψ + Δψ/2) × 有向行程
Δz = -cos(ψ + Δψ/2) × 有向行程
```

因此倒車右打時，車尾向右、車頭向左擺；不是直接旋轉整台車或左右平移。所有鏡頭與輪位皆使用相同車體座標轉換。簡化單軌模型不包含 Ackermann 左右輪轉角差、懸吊、輪胎滑移、真實引擎／變速箱或坡道。

校正值有範圍檢查；前懸由車長減去軸距及後懸計算，避免尺寸互相矛盾。`carConfig.ts` 與 `courseConfig.ts` 的預設值都有 `TODO: NEED USER CALIBRATION` 標記，並非實車量測結果。道路外的景物只作深度參考，不是教練轉向參考點。

### 網站發布

已提供 `.github/workflows/pages.yml`：推送到 `main` 時執行核心測試、建置，再發布至 GitHub Pages。儲存庫的 Settings → Pages → Build and deployment → Source 需設為 **GitHub Actions**。Vite 使用相對資源路徑，支援儲存庫子路徑。

成功發布的實際網址應以 Actions 的 deployment 輸出或 Settings → Pages 為準；工作流程檔案存在或推送成功都不代表網站已上線。

網站尚未啟用時，也可從儲存庫下載 `preview/yongqing-preview.zip`，解壓縮後以桌面 Chrome／Edge 開啟其中的 HTML；這個離線原型不需要 Node.js。

## 使用限制

本模擬器僅作為駕駛觀念與操作順序練習，實際車輛視野、轉向、尺寸與場地可能不同。實際駕駛請以駕訓班教練指導為準。

目前車內儀表／方向盤是介面構圖，車外與鏡面使用三維渲染。實車內裝遮蔽範圍、精確座椅視差與鏡面光學仍需影片及使用者回饋校正。建議桌面鍵盤操作；窄螢幕可操作，但非手機駕駛模擬的最佳化版本。
